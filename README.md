# โต๊ะวิเคราะห์ดีลโรงแรม

เครื่องมือคัดกรองดีลซื้อโรงแรม — กรอกสมมติฐาน แล้วได้ NOI, Yield on Cost, IRR, DSCR,
ราคาสูงสุดที่ควรจ่าย และ Stress Test ทันที

**ไฟล์เดียว ไม่มี backend ไม่มีฐานข้อมูล ไม่ต้องสมัครสมาชิก** — เปิด `index.html` ได้เลย

## ใช้ยังไง

1. กรอกค่าที่แถบซ้าย (ราคาซื้อ จำนวนห้อง Occupancy ADR ต้นทุน เงินกู้ exit cap)
2. ผลลัพธ์ทางขวาคำนวณใหม่ทุกครั้งที่พิมพ์
3. ดู **ราคาสูงสุดที่ควรจ่าย** — ตัวเลขที่ต่ำที่สุดคือเพดานเจรจาจริง
4. กด **คัดลอกลิงก์** เพื่อส่งสมมติฐานชุดนั้นให้คนอื่นเปิดดู (ค่าทั้งหมดฝังอยู่ใน URL)
5. **บันทึกดีล** เก็บไว้ใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ถูกส่งไปไหน

## มีอะไรบ้าง

ครอบคลุมทั้ง 12 ชีตของไฟล์ Excel ต้นทาง ยกเว้นชีต Log (ประวัติการแก้ไฟล์)
และชีตเปรียบเทียบ Thipurai (เทียบสองดีลข้างกัน — อยู่ใน v2)

| ส่วน | มาจากชีต |
|---|---|
| ผลตัดสิน + ตัวชี้วัด 6 ตัว | สรุปผู้บริหาร |
| ช่องกรอก 33 ช่อง พร้อม **ที่มาของตัวเลขทุกช่อง** | สมมติฐาน (รวมคอลัมน์ D) |
| ตารางโมเดล 10 ปี + กระแสเงินสดสะสม + ปีคืนทุน | โมเดล 10 ปี, กระแสเงินสด-ผลตอบแทน |
| ตาราง Sensitivity + Stress Test 7 สถานการณ์ | Sensitivity-Stress |
| **วิธีคำนวณ 20 ขั้น พร้อมค่าสด** | วิธีคำนวณ + คู่มือ |
| **Exit Cap Rate build-up + benchmark + กฎตรวจสอบ 3 ข้อ** | Exit Cap Rate |
| ราคาสูงสุดที่ควรจ่าย (ย้อนกลับจาก 5 เกณฑ์) | เพิ่มใหม่ |
| ราคาต่อห้อง 27 ประกาศ | ภาคผนวก 27 ประกาศ |
| **ลำดับการวิเคราะห์ 9 ขั้น** | คู่มือเริ่มวิเคราะห์ |
| Due Diligence 36 รายการ ติ๊กได้ | DD Checklist |

กดปุ่ม **"ที่มาของตัวเลข — แสดง"** บนแถบซ้ายเพื่อดูว่าค่าตั้งต้นแต่ละตัวอ้างอิงจากไหน

## โมเดล

ค่าตั้งต้นตรงกับไฟล์ `HuaHin_Hotel_Feasibility_76Keys.xlsx` ทุกตัว
(YoC 6.50% · Levered IRR 6.65% · บอลลูนปี 10 = 69.4 ลบ. · ยอดสะสมผู้ถือหุ้น 98.0 ลบ.
· ราคาสูงสุด @ YoC 7.5% = 229 ลบ.)

สองปุ่มสลับที่ Excel ทำไม่ได้:

| สวิตช์ | ค่าตั้งต้น (ตรงกับ Excel) | ทางเลือกที่ถูกต้องกว่า |
|---|---|---|
| โหมดต้นทุน | % ของรายได้คงที่ทุกปี | แยกคงที่ + แปรผัน — ต้นทุนคงที่ไม่ลดตาม occupancy จึงเห็น downside จริง |
| NOI ตีมูลค่าขายต่อ | NOI ปีสุดท้าย | NOI ปีถัดไป (forward) — วิธีมาตรฐานของ direct capitalization |

ตั้ง **ภาษีนิติบุคคล = 0** คือโมเดลก่อนภาษี (เหมือน Excel) · ใส่ 20 เพื่อคิดภาษีจาก
EBITDA − ดอกเบี้ย − ค่าเสื่อมอาคาร · ยังไม่รวมภาษีกำไรจากการขายทรัพย์สินตอน exit

## ทดสอบ

